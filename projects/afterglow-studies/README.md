# Afterglow Studies

**Design · pages · 3 designs**

Design studies for the Afterglow film (`projects/afterglow`), made on the design
canvas: one generated mountain valley, drawn from code and lit by the hour. Open
`index.html` in a browser. The poster and the series take a valley seed, so any
page can grow a new set of mountains.

| Page | What it is |
| --- | --- |
| `index.html` | The project page, with live previews of the three designs |
| `poster.html` | Study No. 02, "Afterglow": poster, 1080 × 1350, with the stages of twilight |
| `day-of-light.html` | "A day of light": 1440 × 900, scrub or play 24 hours (space bar plays and pauses) |
| `four-hours.html` | Study No. 03, "One valley, four hours": the same valley at four times of day, 2200 × 1080 |
| `valley.js` | The landscape engine: seeded ridgelines and stars, and the light at any hour |
| `frame.css`, `frame.js` | The dark viewing room, scale-to-fit and `#embed` mode for previews |
| `canvas/*.dc.html` | The original design-canvas source of each page |

`valley.js` uses the same algorithms as the canvas, so seed 7 draws the same
mountains everywhere. Fonts: Bodoni Moda, Geist and Geist Mono from Google Fonts.
